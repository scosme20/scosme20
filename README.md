## 🚀 About Me

Software Engineer focused on building **scalable backend systems, reliable software architectures, AI-powered applications, and digital products**.

I develop real-world projects while deepening my knowledge of **Software Architecture, Domain-Driven Design, Cloud Computing, Distributed Systems, and AI Engineering**.

My goal is to build software that is:

* easy to evolve;
